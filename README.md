## About

Astral Ascent is a fast-paced roguelite action platformer developed by Hibernian Workshop. Players choose from multiple heroes to escape the Garden, a cosmic prison, by fighting through procedurally generated worlds. With a rich magic system, over 150 spells, and cooperative multiplayer support, Astral Ascent offers deep build variety and replayability for fans of roguelite games.

## Common Problems & Limitations

- **Roguelite Repetition** — Repeated runs required to unlock permanent progression
- **Online Co-op Dependency** — Multiplayer requires stable internet connection
- **Difficulty Spikes** — Some bosses significantly harder than surrounding content
- **Build Dependency** — Runs can feel unwinnable with poor spell combination luck
